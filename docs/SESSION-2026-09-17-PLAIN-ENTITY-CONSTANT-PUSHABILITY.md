# Session 2026-09-17 — Plain Entity constant pushability override

Checkpoint target: converter revision `2026-09-17.85`.

## Scope

This slice expands the first generated plain Entity runtime with one narrowly proven legacy behavior override:

- Forge/Minecraft 1.7.10 `Entity.canBePushed()Z`
- modern 1.21.11 `Entity.isPushable()Z`

Only exact constant boolean implementations are admitted. Signature-changed collision APIs and render-distance overrides remain outside this slice.

## Source proof

`LegacyEntityConstantOverrideAnalyzer` never loads source classes. For a classified `CAN_PUSH` callback it requires the exact executable body:

- `ICONST_0` or `ICONST_1`
- `IRETURN`

Any field read, helper invocation, branch, arithmetic, additional opcode, unsupported descriptor, missing owner, or malformed callback remains unproven.

`LegacyEntityConstantOverridePass` materializes:

`legacyforgebridge/entity-constant-overrides.json`

A proven mapping records exact source owner/method/descriptor, constant boolean value, modern target `isPushable()Z`, and mapping semantics `PUSHABILITY_BOOLEAN_IDENTITY`.

## Admission

`LegacyEntityRuntimeAdmissionPass` now treats classified `CAN_PUSH` as supported only when an exact constant mapping exists for the same source owner/method/descriptor. Dynamic/unproven implementations remain blocked with:

`constant-override-proof-missing:CAN_PUSH`

Admitted rules carry `constantBehaviorOverrides` and an exact override count.

## Generated runtime

`LegacyPlainEntityConstantOverrideCodegenPass` runs after the base generated Entity class pass. It patches only admission-proven targets and currently accepts only:

- source kind `CAN_PUSH`
- target method `isPushable`
- target descriptor `()Z`
- mapping semantics `PUSHABILITY_BOOLEAN_IDENTITY`
- completed source constant proof/runtime-codegen readiness

The generated method is exactly `ICONST_0/1; IRETURN`.

The pass then updates `entity-generated-classes.json` with:

- `constantBehaviorOverrideCodegenComplete`
- `constantBehaviorOverrideCount`
- `constantBehaviorOverrides`

and writes the dedicated codegen report:

`legacyforgebridge/entity-constant-override-codegen.json`

## Fail-closed runtime chain

`LegacyPlainEntityRuntimeCandidatePass` now requires `constantBehaviorOverrideCodegenComplete=true` for every generated plain Entity class, including classes with zero constant overrides. `LegacyPlainEntityRuntimePass` validates the same completion flag again before producing executable runtime rules.

Therefore a source proof without actual generated bytecode, or generated bytecode without the expected proof identity, cannot reach `EntityType` registration/FML remote spawning.

## Deliberate exclusions

This slice does not map:

- legacy `canBeCollidedWith()Z`, because modern collision APIs changed signature/shape;
- `isInRangeToRenderDist(D)Z` / modern render-distance behavior;
- mutable DataWatcher-dependent behavior;
- local legacy `World` construction/spawn callers.

Those require separate semantic proof families.
