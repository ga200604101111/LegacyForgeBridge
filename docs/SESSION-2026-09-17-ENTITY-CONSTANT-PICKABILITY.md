# Session 2026-09-17 — Plain Entity constant pickability override

Checkpoint target: converter revision `2026-09-17.87`.

## Scope

This slice extends the proof-gated constant Entity override family with:

- legacy 1.7.10 `Entity.canBeCollidedWith()Z`
- modern 1.21.11 `Entity.isPickable()Z`

The old method name is misleading: 1.7.10 client ray/entity-selection code checks `canBeCollidedWith()` before considering an entity as the pointed/interactive target. Modern Entity exposes the parameterless targetability hook as `isPickable()Z`; modern physical entity-collision methods have a different, Entity-parameterized shape and are not part of this mapping.

## Proof boundary

Only the existing exact constant boolean body is admitted:

- `ICONST_0` or `ICONST_1`
- `IRETURN`

Dynamic pickability, collision physics, bounding-box behavior, interaction callbacks and any helper/field-dependent implementation remain blocked.

## Mapping IR

`LegacyEntityConstantOverridePass` now supports three constant mappings:

- `CAN_PUSH -> isPushable()Z` / `PUSHABILITY_BOOLEAN_IDENTITY`
- `CAN_COLLIDE -> isPickable()Z` / `PICKABILITY_BOOLEAN_IDENTITY`
- `RENDER_DISTANCE -> shouldRenderAtSqrDistance(D)Z` / `RENDER_DISTANCE_CONSTANT_BOOLEAN_IDENTITY`

Admission and generated bytecode continue to validate target method/descriptor/mapping semantics from the source proof rather than accepting a source-kind label alone.

## Runtime chain

No new runtime mechanism is introduced. The existing chain remains:

source constant proof -> entity runtime admission -> generated plain Entity method -> constant-override codegen completion -> runtime candidate -> executable runtime rule.

Because `CAN_COLLIDE` uses `()Z`, generated `isPickable()` uses one local slot (`this`) and contains only the proven boolean constant plus `IRETURN`.

## Deliberate exclusions

This slice does not map modern `canCollideWith(Entity)` / `canBeCollidedWith(Entity)` physical collision semantics. It also does not expand mutable DataWatcher synchronization or local legacy `World.spawnEntityInWorld` migration.
