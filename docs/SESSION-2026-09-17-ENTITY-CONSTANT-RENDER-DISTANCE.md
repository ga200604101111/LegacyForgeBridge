# Session 2026-09-17 — Plain Entity constant render-distance override

Checkpoint target: converter revision `2026-09-17.86`.

## Scope

This slice extends the `.85` constant Entity override proof/codegen framework with one additional mapping:

- legacy 1.7.10 `Entity.isInRangeToRenderDist(double)Z`
- modern 1.21.11 `Entity.shouldRenderAtSqrDistance(double)Z`

The legacy caller `isInRangeToRender3d` computes `dx² + dy² + dz²` before calling `isInRangeToRenderDist`, and the modern hook is explicitly the squared-distance render decision. This slice still admits only constant boolean bodies, so the generated result is independent of any version-specific threshold formula.

## Source proof

`LegacyEntityConstantOverrideAnalyzer` now accepts only the two explicitly supported boolean callback descriptors:

- `()Z`
- `(D)Z`

For either descriptor the executable body must still be exactly:

- `ICONST_0` or `ICONST_1`
- `IRETURN`

Any use of the double argument, comparison, field read, helper call, branch, arithmetic, or additional executable opcode remains unproven.

## Mapping IR

`LegacyEntityConstantOverridePass` now supports:

- `CAN_PUSH -> isPushable()Z` with `PUSHABILITY_BOOLEAN_IDENTITY`
- `RENDER_DISTANCE -> shouldRenderAtSqrDistance(D)Z` with `RENDER_DISTANCE_CONSTANT_BOOLEAN_IDENTITY`

The sidecar remains:

`legacyforgebridge/entity-constant-overrides.json`

Each mapping retains exact source owner/method/descriptor, target method/descriptor, proof reason, and constant value.

## Admission and codegen

`LegacyEntityRuntimeAdmissionPass` accepts either supported constant override only when the mapping exactly matches the classified source callback identity and the expected modern target/mapping semantics. Missing render-distance proof blocks with:

`constant-override-proof-missing:RENDER_DISTANCE`

`LegacyPlainEntityConstantOverrideCodegenPass` validates the same mapping again before patching generated bytecode. Generated methods remain only `ICONST_0/1; IRETURN`.

The codegen pass no longer assumes all override methods use only the `this` local. It derives instance local slots from the target descriptor with ASM `Type`:

- `isPushable()Z` -> 1 local slot
- `shouldRenderAtSqrDistance(D)Z` -> 3 local slots (`this` + two-slot double)

## Fail-closed boundary

No additional nonconstant render-distance behavior is admitted. In particular, legacy entities that inspect the distance parameter or implement custom threshold/scaling logic remain blocked for a future semantic compiler rather than being approximated.

Collision APIs, riding offsets, mutable DataWatcher behavior, and local legacy `World` spawn callers remain outside this slice.
